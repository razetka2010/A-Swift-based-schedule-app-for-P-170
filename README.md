# Расписание

Приложение для студентов группы **П-170**: расписание занятий и учебные конспекты — в одном месте.

## Возможности

- Просмотр ближайшего занятия и расписания на сегодня.
- Недельный календарь с переходом между неделями.
- Конспекты по предметам: поиск, чтение и публикация.
- Выбор русского или английского языка в профиле.
- Светлая, тёмная и системная темы оформления.

## Требования

- Xcode
- iOS 16.0 или новее

## Запуск

1. Откройте `schedule.xcodeproj` в Xcode.
2. Выберите схему **Рассписание** и симулятор или подключённое устройство.
3. При запуске на устройстве укажите свою команду разработки в **Signing & Capabilities**.
4. Нажмите **Run** (`⌘R`).

Расписание и конспекты загружаются с сервера, поэтому для их просмотра требуется подключение к интернету.
